## Local Development

### Prerequisites
- Node.js (v18+ or v20+)
- npm (v9+ or v10+)

### Setup
```bash
# Clone repository
git clone https://github.com/JamilKhanEmon/JamilKhanEmon.git
cd JamilKhanEmon

# Install dependencies
npm install --legacy-peer-deps

# Create environment configuration
cp env.example .env

# Start local development server
npm start
```
The application will open automatically at `http://localhost:3000`.

### Production Build
```bash
npm run build
```
